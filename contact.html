Easy Steps for pracials

1. Creating and Simulating a Simple Ad Hoc Network (Omnet++ & INET) Steps: a. Open the Omnetpp simulator. b. Navigate to the inet folder → examples → adhoc → idealwireless. c. Load NetIdealRadios.ned and omnetpp.ini files by double-clicking them. d. Run the simulation. e. To increase the number of hosts:  - Use the dropdown menu, select “n host” option and enter the required number (e.g., 7 hosts).

2. Understanding and Analyzing the Routing Table (Cisco Packet Tracer) Steps: a. Create a network topology using routers and PCs. b. Assign IP addresses to interfaces of routers. c. Configure the routing path using RIP protocol. d. Execute the show ip route command on Router1 in CLI mode. e. Analyze the routing information displayed (including directly connected and remote networks).

3. MANET Simulation (Omnet++ & INET) Steps: a. Open Omnet++ and go to inet4 folder. b. Open examples → manetrouting → dymo folder. c. Load DYMONetwork.ned and omnetpp.ini files. d. In omnetpp.ini, go to parameters. e. Add new parameter: **.mobility.speed = 400mps. f. Run the simulation with 5 mobile hosts forming MANET.

4. MAC Protocol Simulation (Cisco Packet Tracer) Steps: a. Create a topology using laptops, smartphones, and tablets. b. Add wireless interface to laptops (they don’t have it by default). c. Copy MAC addresses of each component. d. Convert the MAC addresses to standard colon-separated format. e. Add selected MAC addresses to the wireless MAC filter list of the router. f. Use options to either allow or deny devices access to the wireless network. g. Observe the connectivity status based on the filtering.

5. Simulating Directional Antenna via Home Automation Steps: a. Assign IP addresses to each IoT device (e.g., SmartPhone, Light, Webcam, Garage Door). b. Turn ON IoT services on the server. c. From the server browser, log in and create an account. d. Add the remote server IP to all IoT devices and click “Connect.” e. Login from the smartphone browser into the server. f. Control the devices (Light, Webcam, Garage Door) from the smartphone. g. Apply automation rules like:  - If Light is ON → Webcam ON  - If Light is OFF → Garage Door CLOSE h. Verify rules by observing device behavior.
