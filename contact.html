## ✅ *PRACTICAL NO. 1*

### *AIM:* Use Google and Whois for Reconnaissance.

#### Using WHO.IS

*Step 1:* Open the [WHO.IS](https://who.is) website.
*Step 2:* Enter the domain name (e.g., www.prestashop.com) in the search bar and hit the *Enter* button.
*Step 3:* View the domain registration and ownership information.

## ✅ *PRACTICAL NO. 2*

### *2.1) Use CryptTool to Encrypt and Decrypt Passwords Using RC4 Algorithm*

*Step 1:* Open CryptTool.
*Step 2:* Choose RC4 algorithm for encryption.
*Encryption:* Enter the plaintext and key, and encrypt using RC4.
*Decryption:* Enter the cipher text and key, and decrypt using RC4.

---

### *2.2) Use Cain and Abel for Cracking Windows Passwords (Dictionary Attack) & Wireless Network Passwords*

*Step 1:* Click on *HASH Calculator*.
*Step 2:* Enter a password to generate its hash (e.g., MD5).
*Step 3:* Paste the hash into the cracking field.
*Step 4:* Right-click the hash → Select *Dictionary Attack*.
*Step 5:* Add Wordlist → Select all options → Start the attack.

### *3.1) Using TraceRoute, Ping, Ifconfig, Netstat*

*Step 1:* Open CMD and type:

- netstat

### *3.2) Perform ARP Poisoning in Windows Using Cain & Abel*

*Step 1:* Open Cain & Abel.
*Step 2:* Click *Sniffer* → Click *Start/Stop Sniffer* → Select device → OK.
*Step 3:* Click “+” → Connected hosts will be displayed.
*Step 4:* Go to *ARP tab* → Click “+” → Add targets.
*Step 5:* Click *Start/Stop ARP icon* to begin poisoning.
*Step 6:* Visit any site on the source device.
*Step 7:* Go to *Passwords tab* to view captured credentials.

## ✅ *PRACTICAL NO. 4*

### *AIM:* Using Nmap Scanner to Perform Various Port Scans

*Note:* Install Nmap → Open CMD → Type nmap to verify.

*Commands:*
- *ACK Scan:* nmap -sA -T4 scanme.nmap.org
- *SYN Scan:* nmap -sS -p22,113,139 scanme.nmap.org
- *FIN Scan:* nmap -sF -T4 scanme.nmap.org
- *NULL Scan:* nmap -sN -p 22 scanme.nmap.org
- *XMAS Scan:* nmap -sX -T4 scanme.nmap.org
